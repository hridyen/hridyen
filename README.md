# System Design Philosophy

I approach DevOps as a systems problem.

```text
                 +-------------------+
                 |       CODE        |
                 +---------+---------+
                           |
                           v
                 +-------------------+
                 |   VERSION CONTROL |
                 +---------+---------+
                           |
                           v
                 +-------------------+
                 |       CI/CD       |
                 +---------+---------+
                           |
                           v
                 +-------------------+
                 |  CONTAINERIZATION |
                 +---------+---------+
                           |
                           v
                 +-------------------+
                 |  INFRASTRUCTURE   |
                 +---------+---------+
                           |
                           v
                 +-------------------+
                 |    DEPLOYMENT     |
                 +---------+---------+
                           |
                           v
                 +-------------------+
                 |   OBSERVABILITY   |
                 +---------+---------+
                           |
                           v
                 +-------------------+
                 |    RELIABILITY    |
                 +-------------------+
```

The objective is not simply:

`"Make it work."`

The objective is:

`Make it repeatable → observable → recoverable → scalable.`
